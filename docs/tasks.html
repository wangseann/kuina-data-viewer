  1. Resume your active work first. For a confirmed assignment, run its copied agent claim command. Only your own Native process creates the actual worker claim. If that claim fails, stop before starting work.
  2. Use read-batch TASK_ID to read the exact private catalogue section. Skip eligible records and inspect existing data and metadata first.
  3. Propose one repair per underlying source/instrument/window, combining warnings and numeric fields across batches. Shared scope checks prevent duplicate collection.
  4. Before collection, verify the provider can meet the interval, history and coverage requirements. Use your approved execution environment and bounded resource policy.
  5. Report work and provenance. Data repairs wait for a new matching eligibility audit before verification.
