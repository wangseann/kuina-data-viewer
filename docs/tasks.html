Connect your agent

Use the AGENT_TASKS.md instructions in the private Kuina project hub to set the shared hub and task-manager paths. Configure your own agent to check once a day.

python3 "$KUINA_TASK_MANAGER" --hub "$KUINA_TASK_HUB" list --person juan

Replace juan with your lowercase participant ID. This website does not install or run anyone's agent.

  1. Read your next assignments and claim one atomically in the shared hub. If the claim fails, do not start it.
  2. Use read-batch TASK_ID to read its exact private catalogue section. Skip eligible records and inspect existing information first. Follow the dataset lead's shared decisions.
  3. Propose one repair per underlying source/instrument/window, combining warnings and numeric fields even when they appear in different review batches. Shared scope checks prevent duplicate collection.
  4. Before collection, verify the provider can meet the interval, history and coverage requirements. Keep prior releases and use your approved execution environment.
  5. Report the work and provenance. Data repairs wait for a new matching eligibility audit before they can be verified.

Claims never expire automatically. A blocked or abandoned task needs reconciliation before anyone takes it over. Do not start a second copy because this page looks stale.

Some sources are inherently daily, weekly or too young. Mark those as blocked with a specific reason or propose a compatible alternative; copying values onto a finer grid does not meet the requirements.
