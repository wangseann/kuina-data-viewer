Connect your agent

Use the AGENT_TASKS.md instructions in the private Kuina project hub to set the shared hub and task-manager paths. Configure your own agent to check once a day.

python3 "$KUINA_TASK_MANAGER" --hub "$KUINA_TASK_HUB" list --person juan

Replace juan with your lowercase participant ID. This website does not install or run anyone's agent.

  1. Read your assignment and claim it atomically in the shared hub. If the claim fails, do not start it.
  2. Inspect existing files and metadata first. Propose one repair per underlying source/instrument/window, combining its warnings and numeric fields.
  3. Before collection, verify the provider can meet the interval, history and coverage requirements. Keep prior releases and use your approved execution environment.
  4. Report the work and provenance. Data repairs wait for a new matching eligibility audit before they can be verified.

Claims never expire automatically. A blocked or abandoned task needs reconciliation before anyone takes it over. Do not start a second copy because this page looks stale.

Some sources are inherently daily, weekly or too young. Mark those as blocked with a specific reason or propose a compatible alternative; copying values onto a finer grid does not meet the requirements.
